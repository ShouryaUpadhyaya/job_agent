# 🤖 Job Agent — Autonomous Job Discovery & Intelligent Application Copilot

An end-to-end, multi-agent automated job discovery, evaluation, application, and networking CRM system. Built for software engineers, interns, and fresh graduates to streamline the job hunt across Wellfound, LinkedIn, RSS feeds, ATS APIs, and direct company career portals.

---

## 🌟 Key Features

### 1. ⚡ Wellfound Auto-Apply Control Center
- **Direct Automation Integration**: Seamlessly connects to the Playwright runner and browser automation scripts for Wellfound.
- **Run Modes**:
  - **Dry Run (Safe Test)**: Inspects job postings, validates selectors, generates Gemini AI cover letters, and tests form inputs without submitting.
  - **Live Mode**: Automates submissions while strictly adhering to safety limits and customizable daily application caps (default 25/day).
  - **Visible / Headless Execution**: Run visibly with Chrome or silently in the background.
- **In-Browser Zen Console Script**: Instant generation and one-click copy of the self-contained JavaScript bundle to paste into the browser DevTools console (Zen/Firefox/Chrome).
- **Interactive Profile & Config Editor**: Live management of candidate background, project highlights, CTC expectations, work authorization, notice period, and Gemini API keys directly updating `.env`.
- **Automatic Post-Submission Handling**: Handles post-submission dialogues (e.g., Wellfound "Your AI interview is being shared" confirmation modal) seamlessly.

### 2. 🎯 Job Discovery & Smart Scoring Engine
- **Multi-Source Ingestion**:
  - Lever ATS, Greenhouse ATS, and JSON job APIs
  - RSS feeds and career portal scrapers
  - Web bookmarklet & 1-click URL importer for LinkedIn and Wellfound
- **Rule-Based & Semantic Scoring**:
  - Matches candidate skills against requirements with weighted scoring (0–100).
  - Role classification (`APPLY`, `REVIEW`, `PASS`) prioritizing Intern & Fresher positions.
  - Highlights matched vs missing skills and generates explanatory match reasons.

### 3. 📝 AI Application Copilot & Tailoring
- **Gemini AI Tailoring**: Automatically generates personalized, punchy cover letters tailored to the specific company and role using candidate project highlights and experience.
- **Q&A Form Assistance**: Generates tailored answers for custom employer screening questions.

### 4. 🗂️ Application Pipeline Tracker
- Track applications across stages: `BOOKMARKED` → `APPLYING` → `APPLIED` → `INTERVIEWING` → `OFFERED` / `REJECTED`.
- Synchronizes with `applications.csv` generated by automation runners.

### 5. 🤝 Networking CRM & Contact Finder
- Automatically associates key engineering and recruiting personas (Engineering Manager, Tech Lead, Recruiter) with companies applied to.
- Tracks outreach status, contact info, and follow-up reminders.

### 6. 📬 Daily Briefing & Gmail Sync
- Aggregates daily pipeline summaries and updates.
- Scans Gmail for interview invites, updates, or rejection status (with OAuth token integration).

## 🏗️ Architecture & Tech Stack

```
job-agent/
├── server/                     # Express & TypeScript Backend
│   ├── src/
│   │   ├── api/                # REST endpoints (wellfound, jobs, copilot, networking, etc.)
│   │   ├── connectors/         # Ingestion connectors (Lever, RSS, Wellfound CSV)
│   │   ├── matching/           # Job matching and scoring engine
│   │   ├── scheduler/          # Background cron jobs (ingestion, auto-sync)
│   │   └── app.ts              # Express app configuration
│   └── prisma/
│       └── schema.prisma       # Database schema (PostgreSQL)
│
├── web/                        # Next.js 16 (App Router) & React 19 Frontend
│   └── src/
│       ├── app/                # Pages and routing
│       └── components/         # Interactive UI widgets & dashboards
│
├── scripts/                    # Automation build scripts
│   └── wellfound/              # Bundle compiler for browser automation
│
├── wellfound_autoApply/        # Wellfound Playwright automation engine
├── docker-compose.yml          # Multi-container orchestration (DB, Server, Web)
└── package.json                # Monorepo workspace configuration
```

- **Frontend**: Next.js 16 (Turbopack, App Router), React 19, Tailwind CSS
- **Backend**: Node.js, Express 5, TypeScript
- **Database**: PostgreSQL 15, Prisma ORM
- **Automation**: Playwright, Cheerio, Custom Browser Console Bundles
- **AI / LLM**: Google Gemini API (`gemini-flash-lite-latest`)
- **Testing**: Vitest, React Testing Library, Supertest (36 test suites, 118 tests)

## 🚀 Quick Start with Docker Compose

The easiest way to run the entire system (Database, Backend API, and Next.js Frontend) is using Docker Compose:

### 1. Prerequisites
- [Docker](https://docs.docker.com/get-docker/) & [Docker Compose](https://docs.docker.com/compose/) installed.

### 2. Configure Environment
Copy `.env.example` to `.env`:
```bash
cp .env.example .env
```

Edit `.env` with your settings (especially `GEMINI_KEY` and candidate profile):
```env
# Database
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_DB=job_agent
DATABASE_URL="postgresql://postgres:postgres@postgres:5432/job_agent?schema=public"

# Gemini API
GEMINI_KEY=your_gemini_api_key_here

# Candidate Profile
NAME="Your Name"
EMAIL="your.email@example.com"
PHONE="+91 9999999999"
LOCATION="City, Country"
CURRENT_ROLE="Software Engineer"
COMPANY="Your Company"
SKILLS="JavaScript, TypeScript, React, Node.js, Python, PostgreSQL, Docker"
HIGHLIGHTS="Led development of high-performance microservices, Built real-time web apps"
```

### 3. Start the Services
```bash
# Build and launch all containers in detached mode
docker compose up -d --build
```

Services will be accessible at:
- **Web Dashboard**: [http://localhost:3000](http://localhost:3000)
- **Backend API**: [http://localhost:3001](http://localhost:3001)
- **PostgreSQL**: `localhost:5433` (mapped from container `5432`)

### 4. Stopping the Services
```bash
docker compose down
```

To stop and remove database volumes:
```bash
docker compose down -v
```

## 💻 Local Development Setup (Without Docker App Containers)

If you prefer running Node.js services directly on your host machine while using Docker solely for the database:

### 1. Start PostgreSQL
```bash
docker compose up -d postgres
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Database Setup (Prisma)
```bash
# Push Prisma schema to local database
cd server
npx prisma db push
cd ..
```

### 4. Run the Development Servers
In two separate terminals:

```bash
# Terminal 1: Backend API (runs on port 3001)
npm run dev:server

# Terminal 2: Next.js Frontend (runs on port 3000)
npm run dev:web
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## ⚡ Wellfound Auto-Apply Usage

### Option A: From the Web Dashboard
1. Navigate to **⚡ Wellfound AutoApply** in the dashboard header.
2. Select **🚀 Automation Runner & Live Logs**.
3. Choose your run configuration (**Dry Run** or **Live**, **Visible** or **Background**, and batch size).
4. Click **Start Automation Runner**. View real-time output in the live console window.
5. In the **Applied Roles** tab, review recorded applications and click **📥 Sync to App Database** to populate your pipeline and networking CRM.

### Option B: Zen / Browser Console Script
1. Navigate to the **🌐 Zen Browser Console Script** tab in the dashboard or run:
   ```bash
   npm run wellfound:zen
   ```
2. Click **Copy Script to Clipboard**.
3. Log in to [Wellfound Jobs](https://wellfound.com/jobs) in your browser (Zen, Firefox, Chrome).
4. Open DevTools (`F12` or `Ctrl+Shift+I`) → **Console** tab, paste the code, and press `Enter`.

### Option C: CLI Commands
```bash
# Install Playwright browser dependencies
npm run wellfound:install

# Login to save session cookies
npm run wellfound:login

# Dry run (safe evaluation)
npm run wellfound:dry-run:visible

# Live submission (visible browser)
npm run wellfound:live:visible
```

## 📬 Gmail OAuth & Multi-Inbox Tracking Setup

### 1. Setting Up Google Cloud OAuth 2.0 Credentials
To enable automatic email monitoring for interview invites, application status updates, and recruiter replies:

1. **Open Google Cloud Console**: Navigate to [console.cloud.google.com](https://console.cloud.google.com/) and create a new project (e.g., `Job Agent`).
2. **Enable Gmail API**: Go to **APIs & Services** → **Library**, search for **Gmail API**, and click **Enable**.
3. **Configure OAuth Consent Screen**:
   - Go to **APIs & Services** → **OAuth consent screen**.
   - Select **External** and click **Create**.
   - Fill in App Name (`Job Agent`), User support email, and Developer contact information.
   - Under **Scopes**, click **Add or Remove Scopes** and select:
     - `https://www.googleapis.com/auth/gmail.readonly`
     - `https://www.googleapis.com/auth/gmail.modify` (optional, for labeling/organizing)
   - Under **Test Users**, add your personal Google account email address (required while the app is in testing mode).
4. **Create OAuth Client ID**:
   - Go to **APIs & Services** → **Credentials** → **Create Credentials** → **OAuth client ID**.
   - Application type: **Web application**.
   - Name: `Job Agent Web Client`.
   - **Authorized redirect URIs**:
     `http://localhost:3001/api/gmail/oauth2callback`
   - Click **Create** and copy the generated **Client ID** and **Client Secret**.
5. **Add to `.env`**:
   ```env
   GMAIL_CLIENT_ID=your-client-id.apps.googleusercontent.com
   GMAIL_CLIENT_SECRET=your-client-secret
   GMAIL_REDIRECT_URI=http://localhost:3001/api/gmail/oauth2callback
   ```
6. **Connect in Dashboard**:
   - Navigate to the **Gmail Sync** tab in the Web Dashboard (`http://localhost:3000`).
   - Click **Connect Gmail** and authorize the application.

### 2. Multi-Inbox Tracking: Handling LinkedIn Messages & Connection Requests Across Multiple Inboxes

If you receive LinkedIn notifications, connection acceptance emails, or recruiter messages across different email accounts (e.g., university email, secondary Gmail, work email):

#### **Recommended Approach: Email Auto-Forwarding (Zero Token Overhead)**
You do **not** need to manage multiple complex OAuth credentials. Standard email forwarding is the simplest and most reliable approach:
1. Open your secondary email accounts (Outlook, secondary Gmail, university inbox).
2. Go to **Settings** → **Filters and Forwarding** (or **Rules**).
3. Create a rule matching LinkedIn notifications:
   - **From**: `invitations@linkedin.com` OR `messages-noreply@linkedin.com` OR `*@linkedin.com`
   - **Subject contains**: `"invitation"` OR `"message"` OR `"accepted your connection request"` OR `"new message from"`
4. Set the action to **Forward to your primary connected Gmail account**.
5. Job Agent's Gmail sync will automatically process all incoming emails, correlate them with your applied companies, and update the pipeline and networking CRM seamlessly!
